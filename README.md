# Simple Interest Calculator

This Bash script calculates simple interest from a principal amount, a time period in years, and an annual interest rate expressed as a percentage.

## Run

Install `bc`, then run `bash simple-interest.sh`. Enter the principal, time in years, and annual percentage rate when prompted.

The script calculates `simple interest = principal × years × annual rate / 100`. For example, a principal of 1,000 at 5% for 2 years earns 100 in simple interest.
